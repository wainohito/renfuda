# 連札(Renfuda)— RenkuOS のカード型データベース

**バージョン 0.5(試作版)** · RenkuOS(Haiku 系)x86_64 · MIT License

連札(れんふだ、英語表示では Renfuda)は、RenkuOS のためのカード型データベースです。
HyperCard や FileMaker のように、1 件のデータを 1 枚の「カード」として扱い、カードを束ねた「スタック」で管理します。
カードの見た目(テンプレート)は、部品をドラッグ&ドロップで並べて自由に作れます。住所録、蔵書の管理、名刺の整理、読書メモなど、手元の情報を「札」のように集めて眺めるための道具です。

- スタックは **JSON ファイルの入ったフォルダ** です。特別なデータベースエンジンを使わないので、中身をテキストエディタで読めて、バックアップやバージョン管理も簡単です。
- 画面は **BeOS らしい見た目** を基本に、Haiku・NeXTSTEP・Mac OS・Windows 95 風のテーマに切り替えられます。
- 日本語を前提に作っています。CSV の取り込みでは Shift_JIS・EUC-JP も自動で判定し、PDF にも日本語をそのまま書き出せます。UI は日本語と英語に対応しています。

> **試作版です。** 主な操作は RenkuOS の VM で確認していますが、データ形式は今後変わる可能性があります。大切なデータは、スタックのフォルダごとバックアップしてから使ってください。

## 主な機能

### 3 つのモード

| モード | ショートカット | できること |
| --- | --- | --- |
| **プレイ** | Alt+B | カードを見る・入力する。ボタンやリンク、スイッチを使う |
| **検索** | Alt+F | カードの部品に条件を入れて検索する(スイッチのオン/オフも条件にできる) |
| **編集** | Alt+L | テンプレート(カードのレイアウト)を作る・直す |

モードはステータスバーのボタンで切り替えます。選択中のモードは緑、編集モードは赤で表示され、編集中はカード面の外側の色・バナー・グリッドで、今どのモードにいるかがひと目でわかります。

### カードの部品

オブジェクトパレットから、部品をカードへドラッグして置きます(グリッドにスナップ)。

- **テキスト**(1 行・複数行)、**数字**(小数点以下の桁数を指定して丸め表示)
- **スイッチ**(スイッチ形/チェックボックス形)
- **画像**(ファイルのドロップ、ダブルクリックで等倍表示、URL からの取得)
- **ラベル**、**枠**、**カウンター**、**位置の表示**(「12 / 300」)
- **ボタン**: 最初・前・次・最後のカードへ移動、新規カード、リンクを開く、カードを PDF で保存、カードを画像(PNG)で保存、音を鳴らす、動画を再生する、など
- 部品ごとに、枠線・塗り・フォント・アイコン・リンク・ロックを設定できます(インスペクタ)。
- 前面へ・背面へ、ロック(Alt+K)、取り消し、右クリックのメニューにも対応しています。

### スイッチの動作

スイッチに「オンのあいだの動作」を持たせられます。スイッチの値はカードごとなので、カードごとに見せ方を変えられます。

- **このカードの編集をロック** — 読み終えた本のカードを誤って書き換えないように、など
- **指定した部品をロック** — 選んだ部品だけを読み取り専用に
- **指定した部品を隠す** — 選んだ部品を画面にも PDF にも出さない

### テーマ

同梱のテーマは 5 種類です。テンプレートごとに選べ、部品ごとの指定がテーマより優先されます。

| テーマ | 見た目 |
| --- | --- |
| `beos`(既定) | BeOS 風の立体的な部品 |
| `haiku` | システムの色に追従(色を変えるとすぐにカードにも反映) |
| `nextstep` | NeXTSTEP 風 |
| `macos` | 古典的な Mac OS 風 |
| `win95` | Windows 95 風 |

テーマは `.rfds`(JSON)で書かれていて、`~/config/settings/Renfuda/themes/` に置くと自作のテーマも使えます。部品に付けるアイコンとして、haiku-icons の HVIF アイコン 439 個を同梱しています。

### CSV からスタックを作る

8 画面のウィザード(ファイル → 形式 → 列 → テンプレート → 画像 → 確認 → 取り込み中 → 完了)で、CSV を新しいスタック、または既存のスタックに取り込めます。

- 文字コード(UTF-8 / Shift_JIS(CP932) / EUC-JP)と区切り文字を自動判定。見出し行、先頭の読み飛ばし行も指定できます。
- 列の中身から、テキスト・数字・スイッチ・画像(URL)・リンクのどれにするかを推定し、カードのレイアウトを自動で作ります(収まらなければ 2 列に)。
- 画像の URL からは、画像を取得してサムネイルを作ります(同時 4 接続、タイムアウトと再試行つき、大量のときはバックグラウンド)。
- 10 万行の CSV を約 7.6 秒で取り込めます(画像の取得なし、計測値)。キャンセルすると、新規スタックは何も残しません。

### PDF と画像の書き出し

- 現在のカード、選択したカード、すべてのカード(1 枚 1 ページ、テンプレートの用紙サイズ)、一覧表(用紙と向きを選択、見出しの行を各ページに繰り返す)を PDF に書き出せます。
- 文字はシステムのフォントの輪郭をそのまま埋め込むので、**日本語も文字化けせず、PDF 内で検索・コピーもできます**。JPEG 画像は再圧縮せずに埋め込みます。
- カードを、プレイモードの見た目のまま等倍の PNG にも保存できます。

### リンク

URL を、固定の値として、またはテキスト部品の値から、ボタン・ラベル・画像に設定できます。開けるのは `http` / `https` / `mailto` だけで、初回はスタックごとに確認のダイアログを出します。リンクを開くブラウザは「設定…」(Alt+,)で選べます。

### そのほか

- **一覧表示**: カードを表で見る。複数選択、右クリック、PDF 出力。
- **用紙サイズ**: A4・A5・A6・B4・B5・B6・はがきの 7 種と、自由な大きさ(画面用 512×342 など)。縦/横、プレビューつき。
- **表示倍率**: 25〜300%。プレイ・検索モードでは、ウィンドウがカードにぴったり合います。
- **仮カード**: 新しいカードは、何か入力したときに初めて保存されます。空のカードが溜まりません。
- **プリセットとサンプル**: 住所録・書籍管理・名刺管理のプリセットと、サンプルのスタックを同梱(日本語版・英語版)。
- **Tracker との統合**: スタック・カード・テンプレート・テーマにそれぞれ専用のアイコンが付き、ダブルクリックで開けます。
- **ログ**: 操作の記録を `~/config/settings/Renfuda/logs/` に残します(URL や入力した値は記録しません)。

## インストール

[Releases](../../releases) から次のどちらかをダウンロードします。

### hpkg パッケージ(おすすめ)

```sh
pkgman install ./renfuda-0.5.0-1-x86_64.hpkg
```

`/boot/system/apps/Renfuda/` にインストールされ、Deskbar の「Applications」に「Renfuda」が加わります。

### zip

`Renfuda.zip` を好きな場所に展開し、`Renfuda/Renfuda` を実行します。
プリセット・サンプル・テーマ・アイコン(`presets/`、`samples/`、`themes/`、`icons/`)は実行ファイルの隣から読み込むので、フォルダごと移動してください。
zip ではファイル属性が失われますが、初回起動時にアプリが自分でアイコンと種類を登録します。

### 動作環境

- RenkuOS(Haiku 系)x86_64。2026-10-17 時点の RenkuOS ソースから作った VM で確認しています。
- 必要なライブラリ(libbe、libgame、libtranslation、libtracker、libbnetapi、libz など)はすべて OS の基本パッケージに含まれます。

## 使い方

1. **起動する** — スタート画面が開きます。初回は「最近使ったスタック」にサンプルが並びます(開くと `~/Documents/Renfuda/Samples/` にコピーされます)。
2. **新しいスタックを作る** — 「空のスタック」か、プリセット(住所録・書籍管理・名刺管理)から選びます。空のスタックでは用紙サイズと向きを選びます。CSV から作ることもできます。
3. **カードのレイアウトを作る** — 編集モード(Alt+L)で、オブジェクトパレットから部品をドラッグして置き、インスペクタで名前・スタイル・動作を設定します。部品を選んでいないときのインスペクタでは、テンプレート全体(用紙、背景、テーマ)を設定できます。
4. **入力する** — プレイモード(Alt+B)でカードに入力します。入力は自動で保存されます。カードの移動はボタン、または「カード番号へ移動…」(Alt+G)で。
5. **探す・見渡す** — 検索モード(Alt+F)で条件を入れて検索、一覧表示で表として眺めます。
6. **書き出す** — 「ファイル」メニューから PDF に。

UI の言語は、システムの最優先言語が日本語なら日本語、それ以外は英語になります。

### 主なショートカット

| キー | 動作 |
| --- | --- |
| Alt+B / Alt+F / Alt+L | プレイ / 検索 / 編集モード |
| Alt+G | カード番号へ移動 |
| Alt+K / Shift+Alt+K | 部品のロック / ロック解除 |
| Alt+] / Alt+[ | 前面へ / 背面へ |
| Alt+, | 設定 |

## スタックのファイル構成

スタックは `.rfdf` という拡張子のフォルダで、中身はすべて普通のファイルです。

```
住所録.rfdf/
  住所録.rfdm          マニフェスト(スタックの名前、設定、カードの並び)
  templates/*.rfdt     テンプレート(部品の配置、用紙、テーマ)
  cards/*.rfdd         カード 1 枚ごとの値(JSON)
  media/image/         画像(元画像、サムネイル、背景、アイコン)
  media/audio/         音のファイル
  media/video/         動画のファイル
  themes/*.rfds        このスタックで使うテーマのコピー
```

| 拡張子 | 中身 | MIME タイプ |
| --- | --- | --- |
| `.rfdf` | スタック(フォルダ) | `application/x-vnd.renfuda-*` |
| `.rfdm` | マニフェスト | 〃 |
| `.rfdt` | テンプレート | 〃 |
| `.rfdd` | カード | 〃 |
| `.rfds` | テーマ | 〃 |

保存は「一時ファイルに書いて fsync → 改名」で行うので、途中で電源が落ちても書きかけのファイルは残りません。
データ形式の詳細は [`docs/spec/card-db-spec-v0.4.md`](docs/spec/card-db-spec-v0.4.md) にあります。

## ソースからのビルド

### 必要なもの

- Linux(ホスト)、`g++`(C++17)、`zlib`、`python3`、`zip`
- アプリのクロスビルドには、ビルド済みの RenkuOS のソースツリー(`$RENKU/generated` にクロスコンパイラと開発用パッケージがあること。既定は `~/renku`)

### コマンド

```sh
make test       # core の受け入れテスト(Linux 上で実行)
make bench      # 10 万枚のカードでの計測(build/bench に約 400 MB を使用)
make csvbench   # 10 万行の CSV 取り込みの計測
make data       # プリセット・サンプル・テーマ・文字コード変換表を作り直す
make app        # RenkuOS 向けクロスビルド → build/haiku/Renfuda/Renfuda
make package    # アプリ+同梱データ → build/haiku/Renfuda.zip
make hpkg       # パッケージ → build/renfuda-0.5.0-1-x86_64.hpkg
```

RenkuOS のツリーが別の場所にあるときは `make app RENKU=/path/to/renku` のように指定します。

### テストの結果(v0.5)

- `make test`: 64 ケース、13,676 チェックがすべて成功(AddressSanitizer / UBSan 付きでも問題なし)。データ形式仕様の受け入れテスト、テーマ、CSV(RFC 4180、Shift_JIS/EUC-JP、キャンセル、上限)、PDF(xref の検証を含む)、検索などを含みます。
- `make app`: 警告なしでビルド。実行ファイルが参照するシンボルが、RenkuOS のライブラリですべて解決されることを確認しています。

```

            Json、Model(マニフェスト・テンプレート・カード)、Store(保存)、Stack、Theme、
            Link(URL の検査)、Csv(文字コード判定・変換、取り込み)、Pdf(PDF 書き出し)、
            Preset、Query(検索)、Log

            スタート画面、スタックのウィンドウ、カード面の描画と操作、オブジェクトパレット、
            インスペクタ、CSV ウィザード、画像の取得、PDF 出力、一覧、設定、UI 文言(日英)
presets/    同梱プリセット(ja / en)
samples/    同梱サンプル(ja / en)
themes/     同梱テーマ(beos、haiku、nextstep、macos、win95)
icons/      同梱アイコン(haiku-icons の HVIF、MIT)
tools/      プリセット・テーマ・サンプル・変換表・アプリのアイコンを作るスクリプト

packaging/  hpkg の PackageInfo
docs/       仕様書(docs/spec/)と開発メモ(docs/DEVNOTES.md)
```

## v0.5 の変更点

- **名前を「BDB」から「連札(Renfuda)」に変更**。拡張子を `.bdb*` から `.rfd*` に、設定のフォルダを `~/config/settings/Renfuda` に変更しました。
- **ボタンの動作を追加**: カードを PDF で保存、カードを画像(PNG)で保存、音を鳴らす、動画を再生する(既定のプレーヤーで、元のファイル名のまま開く)。
- **スイッチの動作を追加**: このカードの編集をロック、指定した部品をロック、指定した部品を隠す。
- **画像の枠**: ダブルクリックで等倍表示、クリックでリンク先を開く。
- **設定画面**(Alt+,): リンクを開くブラウザを選べるように。
- **アイコン**: BeOS 風のアプリのアイコン(扇形に重なった 3 枚の札)と、スタック・カード・テンプレート・テーマの専用アイコン。Tracker で種類ごとに表示されます。

> **v0.4 以前からの移行**: 以前のスタック(`.bdbf`)はそのままでは開けません。フォルダと中のファイルの拡張子を `.bdb*` → `.rfd*` に付け替えると開けます(例: `.bdbf` → `.rfdf`、`.bdbd` → `.rfdd`)。以前の設定は引き継がれません。

## 既知の制限

- 部品が重なっているとき、プレイモードでは入力欄が常に上に描かれます。
- 整列ツール、クリップボードからの画像の貼り付けは未実装です。
- 外部でのファイル変更(別のアプリでの編集)は、開いているウィンドウに自動では反映されません。
- `haiku` テーマは色をシステムに合わせますが、部品の形は `BControlLook` では描いていません。
- CSV の画像取得で、robots.txt などによる自動判定はしていません。
- 実機(実際のキーボード・大量のカード・大きな画像)での確認はこれからです。
